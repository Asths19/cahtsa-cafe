# ☕ Cahtsa's Cafe

A personal cafe website project built for fun using HTML, CSS, and JavaScript.

## About

Cahtsa's Cafe is a front-end website designed to create a cozy and inviting cafe experience on the web. This project was created to practice web development skills and experiment with website design.

## Features

- Responsive design
- Modern cafe-themed layout
- Interactive user interface
- Clean and simple navigation

## Technologies Used

- HTML
- CSS
- JavaScript
